positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won’t get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Reflection

Positioning elements is a really useful design tool and something that I will end up coming back to regularly. Where previously, a page's layout was restricted to the default arrangement of elements, the positioning tools open up a toolkit that allows me to place elements exactly where I intend for them to be.

Something I'll have to keep in mind is that absolute positioning cannot be used on an element unless a relative position is applied to its parent container. This makes sense in concept but may be something that I forget about in practice.

Z-index is a tool that is particularly useful. The ability to layer elements opens up a 3 dimensional nature to designing the page. I could see this being extremely useful for more complex layouts that feature many layers of elements and images. It could even be interesting in an interactive way, where certain elements change their depth on the page depending on what information the user chooses to focus on.
